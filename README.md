## AI Skincare Detector

### Project Overview

This is a simple Java-based program that helps users identify their skin type and provides basic skincare advice. It asks the user a few questions related to skin conditions such as oiliness, dryness, and acne. After getting the user input, it determines the type of skin.

The aim of this project is to demonstrate the application of basic programming concepts in solving a real-life problem in a simple and understandable way.

### What the Project Does

*   It asks the user a few questions related to skin conditions.
*   It determines whether the user has oily skin, dry skin, or acne.
*   It uses simple if-else conditions to determine the type of skin.
*   It displays the type of skin.
*   It provides basic skincare advice.

### Requirements

To run this project, the user requires the following:

*   Java JDK must be installed in the system (version 8 or above).
*   A terminal or command prompt or any Java IDE (VS Code, IntelliJ, Eclipse) must be available.

### How to Set Up and Run

#### Step 1: Download the Code

The user must download the code from the repository.

#### Step 2: Open the Folder

The user must go to the folder where the file `App.java` is available.

#### Step 3: Compile the Program

The user must open the terminal in the folder and type the following command:

```bash
javac App.java
```

#### Step 4: Run the Program

After this, execute the following command in the command prompt to run the program:
java App

---

## How to Use

1. Run the program
2. You will see questions on the screen
3. Enter your answers as follows:

   * 1 for Yes
   * 0 for No
4. Press Enter after each input
5. You will see your skin type and suggestions
